# Adam Marks

Personal site, live at https://adammarks1990.github.io/adam-marks/

## Versions
The plain link is the general version. Add `?for=<key>` to show a tailored one:

- https://adammarks1990.github.io/adam-marks/?for=masterclass

To add a version, open `index.html`, find `const VERSIONS`, copy the `masterclass` block, give it a new key and change the lines.
